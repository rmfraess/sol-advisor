# Sol Advisor Hermes bootstrap

For every implementation, refactoring, or debugging task in this repository:

1. Read `AGENTS.md` and its relevant linked guidance.
2. Load the plugin-qualified `sol-advisor:sol-advisor` skill before planning or delegating work.
3. Follow that skill's primary-orchestrator, Luna-worker, verification, correction, and acceptance flow.

The installed Sol Advisor plugin injects this policy into every top-level turn and
skips delegated children using Hermes' `parent_session_id` hook argument. Do not
bypass this flow unless the user's current request explicitly asks for a
different workflow. Read-only questions and documentation lookup do not require
delegation.
